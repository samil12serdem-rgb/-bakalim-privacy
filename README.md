# -bakalim-privacy

BAKALIM'ın yasal sayfaları artık https://bakalimapp.com adresinde yayınlanır
(kaynak: `bakalim-app` reposu, `site/public`). Bu GitHub Pages sitesindeki
sayfalar, eski uygulama sürümlerindeki bağlantılar çalışmaya devam etsin diye
yalnızca resmi sayfalara yönlendirir:

| Eski adres | Yeni adres |
|---|---|
| `/` | https://bakalimapp.com/gizlilik |
| `/kvkk.html` | https://bakalimapp.com/kvkk |
| `/terms.html` | https://bakalimapp.com/kullanim-kosullari |
| `/delete-account.html` | https://bakalimapp.com/hesap-silme |

Metin değişiklikleri burada değil, `bakalim-app/site/public` içinde yapılır.
